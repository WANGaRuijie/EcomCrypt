## What this project is
A static research directory (site/) of papers at the intersection of EconCS / economics / finance / OR-MS and blockchain / cryptography / security / systems. Built from append-only data files in data/; site/data/directory.json is regenerated by `python scripts/build.py build`.

## Rules
- Before every push: `python scripts/build.py build`, then `python scripts/dedupe.py report`, and decide each pair in data/work_merges_v1.json from the abstracts; push only when `python scripts/dedupe.py check` passes. Merges fold two works into one entry at build time; the ledger is untouched.
- The CCF list is a reference for finding missed venues (`python scripts/ccf_gaps.py <pdf>`), never a verdict on tier or admission. The user disagrees with many CCF grades.
- After changing rubric wording, read a sample of the new exclusions before trusting them. The screening model applies a clause beyond its stated scope (a SoK-only line once excluded 80 ordinary preprints).
- Never edit data/accepted_updates_v1.json except through promote. The ledger is append-only. Removals happen at build time through the policy files.
- One DeepSeek budget per run (default $2, set in data/pipeline_config_v1.json). The ChatGPT-era ledger .cache/expand/campaign-3usd.json is separate; leave it alone.
- Ask the user before raising the LLM budget, adding or denying venues in bulk, or removing directory papers.
- Unverified details to check on the first live run: the dblp booktitle/journal strings in the registry (see CHATGPT_TASKS T1), OpenAlex boolean syntax inside `title_and_abstract.search`, and the Dagstuhl release URL pattern.
